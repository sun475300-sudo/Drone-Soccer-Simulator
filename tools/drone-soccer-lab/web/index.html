사용 안내

1. 영상 파일을 엽니다. H.264 MP4가 가장 호환성이 좋습니다.

2. 화면에서 기체를 둘러싸는 작은 사각형을 드래그합니다. 최대 10대를 직접 등록할 수 있습니다.

3. 종료점을 짧게 지정하고 추적합니다. 같은 색 기체·그물·빠른 움직임에서는 다른 물체를 따라갈 수 있으므로 반드시 확인합니다.

4. 잘못 따라가면 중지하고 해당 장면으로 이동하여 ‘선택 기체 위치 수정’을 누릅니다. 이후 궤적은 다시 추적합니다.

5. 이벤트는 사람이 기록합니다. JSON을 저장해야 종료 후 복원할 수 있습니다. 원본 영상은 JSON에 포함되지 않으므로 같은 파일을 다시 여세요.

키보드: Space 재생/일시정지, ←/→ 근사 프레임 이동. 저장: Ctrl+S.
