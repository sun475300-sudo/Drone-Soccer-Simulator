# Drone Soccer Lab · 드론축구 복기실

**0.1.0-preview / 2026-11-15 / 사람 검토가 필요한 시험판.**
기존 Imperial Wings 시뮬레이터와 별개의 로컬 영상 복기 프로그램입니다. 비행 제어·USB 조종·시뮬레이터 코드를 변경하지 않습니다.

## 시작
1. Windows x64용 `DroneSoccerLab.exe`를 실행합니다. 기본 브라우저에 한국어 화면이 열립니다. Python·Go·GPU 모델 설치는 필요하지 않습니다. Edge/Chrome 계열 브라우저에서 먼저 확인하세요.
2. **영상 파일 열기 → 기체 선택 영역 그리기 → 현재 위치부터 추적** 순서로 사용합니다. 기체를 작은 사각형으로 지정하고, 잘못 따라가면 중지한 뒤 **선택 기체 위치 수정**으로 다시 지정합니다. 최대 10대를 기록할 수 있습니다.
3. 이벤트를 수동 기록하고 **프로젝트 JSON 저장**을 누릅니다. 나중에 같은 영상 파일을 먼저 연 뒤 JSON을 불러옵니다. 종료는 화면 우측 위 **프로그램 종료**를 사용하세요. 브라우저 탭만 닫으면 로컬 실행 프로세스는 남습니다.

브라우저가 열리지 않으면 `%APPDATA%\DroneSoccerLab\session.txt`에 적힌 현재 로컬 주소를 브라우저에 붙여넣으세요. 주소는 실행마다 바뀝니다. 관리자 권한·방화벽 예외·외부 서비스 계정은 요구하지 않습니다.

## 구현된 기능
- 로컬 여러 영상 목록, 재생 속도, 입력 FPS 기반 근사 프레임 이동, 구간 반복
- 수동 기체 영역/팀/역할 지정 및 이미지 템플릿 기반 보조 추적
- 기체별 2D 궤적, 화면상 표본 밀도 히트맵, 화면속도(px/s)
- 공격·득점·방어·복귀·충돌 의심 등 **사용자 확인 이벤트**
- JSON 저장/복원, 궤적·이벤트 CSV, 주석 화면 PNG, HTML 복기 보고서
- 프로젝트 입력 검증, HTML/CSV 이스케이프, 추적 실패/겹침 중단

## 반드시 구분할 한계
학습된 AI 탐지기나 자동 심판이 아닙니다. 사람이 선택한 이미지 조각을 다음 표본에서 찾는 실험적 보조 추적입니다. 그물망·작은 기체·가림·흔들림·줌·기체 겹침에서 다른 물체를 따라갈 수 있습니다. 표시된 유사도는 정확도나 확률이 아닙니다. 높은 유사도에서도 잘못된 ID가 가능하므로 사람이 궤적을 확인해야 합니다.

좌표는 영상 화면의 정규화된 2D 좌표입니다. 카메라 이동 보정, 실제 거리/속도, 3D 복원은 없습니다. 바닥 평면을 맞춘 것만으로 공중 기체의 실제 좌표가 되는 것도 아닙니다. 속도는 같은 segment 내 0.30초 이하 간격의 유효한 점 쌍에 대해서만 계산하며, 빈 값은 측정되지 않았음을 뜻합니다. 프레임 이동은 입력 FPS의 근사치이며 가변 FPS 영상의 정확한 원본 프레임 번호나 디코더 PTS를 보장하지 않습니다. 히트맵은 표본 밀도이지 경기장 점유율이 아닙니다.

규정 선택은 프로젝트 메모일 뿐 자동 규정 엔진이 아닙니다. FIDA Class40/Class20과 FAI 규정은 구별하고 해당 대회 당시 규정을 직접 확인해야 합니다. 득점/충돌은 자동 확정되지 않습니다. 수동 추적·이벤트도 실제 경기 정답으로 검증되었다는 뜻은 아닙니다.

## HEVC 영상이 열리지 않을 때
재생 지원은 브라우저·Windows 코덱에 따라 다릅니다. 동봉한 `scripts/convert-h264.cmd`에 영상 파일을 끌어 놓으면, 사용자가 미리 준비한 `ffmpeg.exe`를 이용해 **별도 `_h264.mp4` 파일**을 만듭니다. 원본은 덮어쓰지 않습니다. FFmpeg는 동봉하거나 자동 설치하지 않습니다. 공식 안내: https://ffmpeg.org/download.html

FFmpeg를 스크립트와 같은 폴더에 두거나 PATH에 등록한 상태에서 사용하세요. 변환 후에는 변환본으로 새 프로젝트를 시작해야 합니다. 변환본과 원본은 프로젝트에서 다른 파일입니다. 인터넷 URL을 가져오거나 플랫폼 다운로드 제한을 우회하는 기능은 없습니다.

## 개인정보와 파일
영상은 브라우저의 로컬 File/Blob으로 열리며 서버에 업로드하지 않습니다. 실행파일은 127.0.0.1의 임의 포트에 내장 UI만 제공합니다. 외부 네트워크 API, 텔레메트리, 로그인 기능이 없습니다. 생성한 JSON/CSV/PNG/HTML에는 파일명·메모·영상 일부가 포함될 수 있으므로 공유 전에 확인하세요. 원본 영상은 프로젝트에 포함되지 않습니다. 자동 영구 저장은 없으므로 JSON 저장이 필요합니다.

## 검증 상태
로컬 Linux 환경에서 Go HTTP/보안/종료 테스트 3개와 Node 코어 테스트 12개가 통과했습니다. 격리된 메모리 브라우저에서 합성 H.264 이동 추적(31점, 최대 x 오차 약1.94px), 드래그 지정, 이벤트, JSON 복원, CSV/HTML/PNG 저장, 실제 사용자 H.264 표본 열기·이동을 확인했습니다. 이 결과는 합성 예제와 기능 검사이며 실제 경기의 추적 정확도나 모든 코덱 검증이 아닙니다.

테스트 환경의 localhost 브라우저 탐색이 차단되어 브라우저 UI와 HTTP 서버는 분리 검사했습니다. GitHub Windows 워크플로가 성공한 릴리스는 네이티브 EXE 자체검사와 HTTP 기동·종료 검사를 추가로 통과합니다. **사용자 Windows PC의 화면·HEVC·전체 복기 흐름·장시간 사용은 별도 검증 대상**입니다. 실행파일은 코드서명하지 않은 시험판입니다. 보안 경고를 임의로 무시하지 말고 출처와 SHA-256을 확인하세요.

## 개발과 재현
```sh
go test ./...
node --test tests/core.test.cjs
go run . -no-open
# Windows에서 빌드
go build -trimpath -ldflags "-s -w -H=windowsgui" -o DroneSoccerLab.exe .
```
Go 표준 라이브러리와 직접 작성한 JavaScript만 사용합니다. `scripts/smoke-windows.ps1`은 Windows 실행파일의 실제 기동/종료를 검사합니다. 연구 범위·한계는 `docs/plan.md`, 공개 영상 목록은 `docs/sources.csv`를 참고하세요. 공개 저장소에 사용자 원본 영상·영상 캡처·개인 프로젝트를 넣지 않습니다.
