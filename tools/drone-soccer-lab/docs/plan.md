# 드론축구 영상 복기 프로그램 개발 계획서
기준일: 2026-11-15. 현재 구현: 0.1.0-preview. 아래 목표/검수 기준은 제안이며 실측 성능이 아니다.

## 1. 결론과 범위
사람이 기체를 지정하고 추적 결과를 수정하는 2D 복기 도구는 구현 가능하며 시험판을 제작했다. 단일 관중 영상으로 모든 기체 ID·실제 3D 속도·공식 득점을 완전 자동 확정하는 제품으로 설명해서는 안 된다. 우선 목표는 코치가 장면을 찾고, 근거를 남기고, 수작업 복기 시간을 줄이는 것이다. 시뮬레이터·자동비행·경기 판정 시스템은 별도 범위다.

## 2. 실제 확인한 자료와 한계
사용자가 올린 파일 7개를 바이트 해시로 중복 제거한 결과 원본은 4개, 총 약269.2초였다. 3개는 HEVC, 1개는 H.264였다. 각 영상의 10/30/55/80% 시점, 총16개 표본 프레임을 시각 점검했고 H.264 표본의 브라우저 디코딩을 확인했다. 관찰한 문제는 전경 그물망, 원근 왜곡, 작은 기체, 기체 겹침, 카메라 이동, 세로 영상의 검은 여백이다. 전 구간 정답 라벨링이나 득점·선수별 전술 복기는 수행하지 않았다.

공개 웹에서는 FIDA 전주2025 공식 페이지의 7개 영상 항목, FAI 상하이2025 공식 재생목록 안내 1개, TSS/JDSF 히로시마2026 결승·3위전 2개를 식별했다. 총10개 목록 항목이며 10경기를 전부 시청했다는 뜻이 아니다. FIDA 7개 중 개막식·종합 하이라이트도 포함한다. 인터넷의 모든 영상 수집·전수 복기는 완료하지 않았고 완전성을 보증하지 않는다. 공개 페이지의 제목/임베드/목록 링크 확인과 실제 영상 프레임 검토는 별도 상태로 관리한다. 인스타그램 참고 릴스의 실제 영상은 접근되지 않아 화면·효과 일치 여부를 확인하지 못했다. 출처 목록은 sources.csv에 있다.

## 3. 규정과 용어
FIDA 공식 규정 HTML은 2025-10-01 제5차 개정, 2026-01-01 시행으로 표시된다. Class40의 권장 경기장은 16×7×4.5m이며 역할과 득점 조건을 포함한다. FAI 공식 요약은 F9A-A/F9A-B를 구분하고 2026판 v2의 2026-06-01 시행을 안내한다. 두 체계를 혼합하지 않는다. 과거 경기에는 당시 대회 규정 판본을 적용하고 변경 이력을 저장한다. 현재 규정 드롭다운은 기록용 메모일 뿐 판정 엔진이 아니다. [S1,S2]

## 4. 구현된 시험판
로컬 영상 열기, 재생·구간 반복, 최대10대 수동 영역 지정, 이미지 템플릿 추적, 재지정, 화면 궤적·표본 밀도 히트맵, 수동 이벤트, JSON/CSV/PNG/HTML 저장을 제공한다. Go 표준 라이브러리 실행파일 안에 UI를 포함하고 127.0.0.1에만 바인딩한다. 영상은 브라우저 File/Blob으로 읽는다. 외부 업로드, 학습 모델, 자동 판정, 실제 좌표 보정은 포함하지 않는다. 유사도는 확률이 아니며 사람 검토를 요구한다.

## 5. 후속 기술 설계
입수·권리 등록 → 중복 해시/메타데이터 → 장면 분할·시간 정렬 → 기체·골대·가림 라벨 → 도메인 맞춤 탐지 → 다중 객체 추적 → ID/역할 수동 확인 → 이벤트 후보 → 코치 승인 → 보고서 순서로 확장한다. ByteTrack은 탐지 결과를 시간적으로 연결하는 후보이며, 그 자체가 드론 탐지·팀 식별·득점 판정 모델은 아니다. 모델의 라이선스와 배포 조건을 먼저 검토한다. [S3]

카메라 이동은 배경 특징의 강건한 추정으로 보정하되 보정 실패/줌/컷을 탐지하고 해당 구간을 별도 segment로 끊는다. 화면 밖이나 가려진 기체는 좌표를 날조하지 않고 missing으로 기록한다. 드론의 색·태그·초기 팀 지정은 증거가 있을 때만 사용한다. 바닥 호모그래피는 공중 물체의 3D 좌표를 제공하지 않는다. 실제 공간 분석은 동기화된 복수 카메라, 내·외부 보정, 검증용 기준 위치와 오차 측정이 확보된 별도 단계로 둔다.

## 6. 복기 이벤트와 정답 체계
공격 시도: 코치가 골잡이와 목표 골대를 지정하고 진입/이탈 시점을 기록한다. 득점: 영상 통과만으로 단정하지 않고 역할·방향·복귀·심판 표시 등 해당 규정의 근거를 확인한다. 방어 성공: 단순 근접을 성공으로 세지 않고 공격 결과와 방어 기체의 개입을 함께 검토한다. 충돌: 화면 겹침은 충돌 의심으로만 기록한다. 라벨은 관찰 사실/해석/확정 여부를 구별하고, 두 검토자의 불일치와 판정 근거를 남긴다.

## 7. 데이터와 권리
1차 파일럿 제안은 사용 권한이 확인된 서로 다른 촬영 조건의 경기 5개에서 정상·가림·골대 앞 혼전 등 짧은 구간을 추출하는 것이다. 이는 확보 완료 수량이 아니다. 정답 라벨에는 frame/media time, bounding box, visible/occluded/out-of-view, temporary track ID, 확인된 team/role, event, reviewer를 둔다. 원본/프록시/라벨 버전·SHA-256·촬영 권리와 분석/학습/재배포 허용 범위를 관리한다.

공개 시청 가능 여부를 원본 다운로드·학습·재배포 허가로 간주하지 않는다. 공식 임베드/링크를 우선하고 다운로드 제한 우회나 무단 일괄 수집을 구현하지 않는다. 원본·개인 얼굴·참가자 정보·사용자 복기 파일은 공개 Git에 넣지 않는다. 사용자의 프로그램 업로드 요청과 원본 영상 공개 허가는 별개로 취급한다. YouTube 이용약관 및 각 권리자의 조건을 확인한다. [S4]

## 8. 검증 계획과 수용 기준(제안)
G0 기능 기준: 같은 영상에서 JSON 재열기 후 라벨·이벤트가 일치하고 모든 출력이 열려야 한다. 잘못된 데이터와 빈 영상, 가변 FPS·한글/공백 경로·종료/취소를 검사한다.
G1 정확도 기준: 경기/대회 단위로 학습·검증·시험을 분리한다. 이웃 프레임을 무작위 분리해 점수를 부풀리지 않는다. 탐지 recall/precision, IDF1/HOTA, ID 전환/분, 가림별 유지율, 이벤트 후보 recall/오경보, 코치 수정 시간을 보고한다. 라벨이 확보되기 전 수치를 성능으로 제시하지 않는다.
G2 실용성 기준: 동일 코치의 수동 복기와 보조 복기를 교차 비교한다. 복기 시간 30% 감소를 초기 사업 목표로 제안하되 정확도 저하와 누락이 없는지 같이 평가한다. 표본이 작으면 구간별 결과와 불확실성을 그대로 보고한다.
G3 배포 기준: Windows 네이티브 빌드·자체검사·루프백 서버 검사를 통과하고, 별도 Windows PC에서 실제 영상 열기→기체 지정→저장→종료→재열기 흐름을 확인한다. 체크섬과 소스 커밋을 연결한다. 미검증 항목은 릴리스에 표시한다.

## 9. 단계별 작업 패키지
P0(현재): 반자동 로컬 복기 도구·단위 검사·출력 형식·배포 스크립트. 완료 범위는 README 검증 기록과 실제 빌드 결과에 한정한다.
P1: 권리 확인, 촬영 조건별 목록과 정답 라벨, 2명 검토, 베이스라인 성능과 실패 유형. 통과 조건은 재현 가능한 데이터 분리와 정답 합의다.
P2: 맞춤 탐지·카메라 이동 보정·다중 객체 ID 연결, 저신뢰 검토 큐. 통과 조건은 P1 대비 ID 전환·수정 시간 개선이다.
P3: 규정 버전별 공격/복귀/득점 후보, 심판/코치 승인 인터페이스, 비교 보고서. 통과 조건은 이벤트 근거와 누락/오경보 감사다.
P4: 동기화 다중 카메라와 보정 실험. 실제 3D 위치·속도는 실측 오차 검증을 통과한 경우에만 표시한다.

전 단계의 일정을 지금 확정하지 않는다. 필요한 인력은 영상/CV 개발, Windows/UI 개발, 드론축구 규정·코칭 검토, 라벨 작업이다. 비용은 허가 영상 시간×라벨 작업률, GPU 실측 사용시간, 다중 카메라/보정 장비, 코드서명 등으로 견적화하며 현재 예산·개발기간은 산정 전이다.

## 10. 현재 검증 결과와 미완료
Go 3개, JavaScript 코어 12개 검사 통과. 메모리 페이지 브라우저 기능 검사에서 합성 이동31점의 최대 x 오차1.94px, 수동 지정·이벤트·JSON 복원·CSV/HTML/PNG 출력, 사용자 H.264 표본 재생을 확인했다. 합성 영상 결과를 실제 대회 정확도로 일반화하지 않는다. 환경 제한으로 통합 localhost 브라우저 실행은 확인하지 못했고 UI와 HTTP를 분리 검사했다. Windows 네이티브 검사 결과는 GitHub 워크플로 기록을 따르며 별도 PC·HEVC·장시간·대회 전 구간·3D·자동 득점은 미검증이다.
