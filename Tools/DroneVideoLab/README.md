# 드론축구 영상분석실 · Drone Video Lab

**0.1.0-preview — 사람이 검토하는 영상 복기 도구입니다. 완전자동 경기 분석기나 자동 심판이 아닙니다.**

이 폴더는 기존 Unreal 드론축구 시뮬레이터와 별개 프로그램입니다. 시뮬레이터의 코드·main 브랜치·최신 정식 릴리스 설정을 변경하지 않습니다. 사용자의 원본 영상은 저장소와 배포물에 포함하지 않습니다.

## Windows에서 사용하기

별도 `video-lab-*` 시험판 릴리스에서 Windows x64 ZIP을 받아 압축을 풀고 `DroneVideoLab.exe`를 실행합니다. Python을 별도로 설치할 필요가 없습니다. EXE만 받아 실행할 수도 있습니다. 코드 서명이 없는 시험판이므로 게시자와 SHA-256을 확인하고 조직의 보안 정책을 따르세요. 보안 프로그램을 끄지 마세요.

권장 대상은 Windows 11 x64와 1280×800 이상 화면입니다. Windows CI 시험은 Windows Server 2022 환경이며 개인 Windows PC 전체 호환성을 보증하지 않습니다. GPU는 요구하지 않습니다.

1. **영상 열기**에서 MP4 등을 선택합니다. 여러 파일은 오른쪽 목록을 두 번 눌러 전환합니다.
2. 일시정지 후 기체 이름·팀을 정하고 **기체 주변을 드래그**합니다. 다음 기체는 **새 기체**를 누릅니다.
3. 오른쪽 화살표로 다음 프레임을 보거나 재생합니다. 추적은 유사한 그림을 찾는 실험 기능입니다. 가림·겹침·유사도 부족 시 멈추지만 모든 오인을 찾아내지는 못합니다.
4. 기존 기체를 목록에서 선택하고 다시 드래그하면 위치를 수정합니다. 같은 프레임 기록은 대체되며 마지막 수동 편집은 Ctrl+Z로 되돌릴 수 있습니다. 되돌리면 그 편집 이후 추적 결과도 복원됩니다.
5. 사건을 수동 기록하고 **프로젝트 JSON**, **CSV**, **PNG**, **궤적 MP4**로 저장합니다. JSON에는 영상 자체가 없으므로 원본을 별도 보관하세요.

Space: 재생/정지 · ←/→: 한 프레임 · Ctrl+S: 저장 · Ctrl+Z: 마지막 수동 편집 복원 · F1: 도움말.

## 구현 범위와 중요한 한계

- 수동 기체 위치와 자동 추적 후보를 `manual` / `candidate`로 분리합니다. 추적 점수는 정확도 확률이 아니라 템플릿 유사도입니다. 일반 물체 검출·재식별 모델을 학습하지 않았습니다.
- 위치는 영상 픽셀입니다. CSV의 `image_speed_px_s`는 카메라 움직임을 포함한 화면상의 변화이며 실제 기체 m/s가 아닙니다. 단안 영상에서 보장된 3D 좌표를 산출하지 않습니다.
- 그물, 작은 기체, 기체 겹침, 크기/조명 변화, 카메라 이동에서 실패할 수 있습니다. 탐색·역재생·구간 반복 이후에는 추적 대상을 재지정해야 합니다.
- 서로 다른 추적 구간/누락 프레임 사이에 궤적이나 속도를 연결하지 않습니다. 화면에 보이지 않는 기체 위치를 확정값으로 만들지 않습니다.
- 재생·출력은 **무음**입니다. MP4 출력은 원본 평균 FPS의 고정 프레임률이며 VFR 원본과 시간 길이가 달라질 수 있습니다. 프레임·컨테이너 타임스탬프·시간 출처는 JSON/CSV에 따로 남깁니다.
- 위치 분포 그림은 **관측 프레임 수**입니다. 체류 시간이나 실제 경기장 히트맵이 아닙니다. 카메라가 움직이는 영상끼리 비교하지 마세요.
- 사건과 득점은 사용자가 기록한 내용이며 공식 심판 판정을 대신하지 않습니다. 현재 버전은 특정 대회 규칙을 자동 적용하지 않습니다.
- 모든 영상 처리는 로컬에서 실행합니다. 네트워크 호출, 계정, 자동 업로드, 인터넷 영상 다운로드 기능이 없습니다.

## 개발 및 검증

Python 3.12에서 `python -m pip install -r requirements.txt` 후 `python app.py`로 실행합니다. Windows EXE 제작은 PowerShell에서 `./build-windows.ps1`을 실행합니다. 스크립트는 별도 `.venv`에 의존성을 설치하고 단위 테스트, 합성 MP4/Tk GUI 검사, PyInstaller 패키징, 한글·공백 경로로 옮긴 EXE 검사를 순서대로 수행합니다. 관리자 권한은 필요하지 않습니다.

`python -m unittest discover -s tests -v`와 `python app.py --smoke-test verification/local`로 검증합니다. 합성 검사는 실제 대회에서의 추적 정확도 성적이 아닙니다. 실패하면 릴리스를 게시하지 않습니다. 빌드 출처는 릴리스의 커밋과 Actions 실행, 파일 무결성은 SHA256SUMS로 확인합니다. 다른 PC·장시간·대회 전수 검사, 코드 서명은 후속 검증입니다.

## 자료와 권리

공개 영상의 링크 발견은 전체 경기 시청이나 학습/재배포 허락을 뜻하지 않습니다. 대회별 주최자·규정 버전·촬영 조건·이용 허락을 별도 관리해야 합니다. 원본과 인물 영상은 이 배포물에 넣지 않습니다. 제3자 패키지의 원문 라이선스는 빌드 환경에서 수집해 ZIP의 `licenses/` 및 EXE에 포함합니다.
