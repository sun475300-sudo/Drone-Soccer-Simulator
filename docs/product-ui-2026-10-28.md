## 구현한 범위

- HUD 측정·그리기에 같은 최소10px 요청 크기, UTF-16 문자 쌍을 보존하는 말줄임을 적용했다. 실제 Windows 장치명은 번역 사전을 거치지 않는다. 잘린 상태/장치명에는 읽기 전용 hover 상세를 추가했다. 전체 글리프 높이·접근성·모든 DPI를 보장하지 않는다.
- AI 설정 또는 저장 완료 결과의 저장 기록 비교에서 기준A·비교B를 직접 선택한다. 목록5개/상세8개씩 표시하고 조건 불일치·자동 검사·중도 종료·중복 세션은 이유와 함께 차이 계산을 차단한다. 명시적으로 열거나 새로고침할 때만 읽고 파일명 순서의 최대100개 후보·추가 생략 수를 표시한다.
- UI는 C++ 로더/모델을 사용한다. Python을 실행하지 않는다. 입력은 AI 결과 schema1/2이고 F6 JSONL/F5 CSV는 지원하지 않는다. 원본 편집·삭제·전송 버튼은 없다. 65,536바이트·UTF-8·중복 키·자료형/범위·UTC·기체 목록을 검사한다. 깊이64·연결파일·일부 비표준 날짜에 대한 native 추가 제약은 CLI와 완전히 동일한 모든 입력 지원을 뜻하지 않는다.
- 허용된 값은 B−A의 기술 통계다. 입력·레이트·배터리·시작 움직임·프레임률을 이 기록으로 검증할 수 없으며 실력 향상이나 온라인 기록을 인증하지 않는다. 실제 사람 기록 두 개의 검증은 남았다.
