- 한국어/영어, 기본 응답·부드러운 프리셋·고급 설정 분리, 720p용 모달·안내 확대. AI 설정/결과 문구 81개와 진행 중 설정 변경 차단을 통합했습니다.

- 설치기에서 새 폴더 설치/기존 버전 업데이트를 선택합니다. 검증한 전체 파일을 준비한 뒤 교체하고 이전 프로그램을 백업합니다. 개인 설정·기록은 삭제하지 않습니다.

- 전체 6단계의 연속 실제 키보드 비행·첫 골·마지막 착륙 완주와 초보자 독립 사용성은 미검증입니다. 단계 판정의 순수 상태190개와 native/OS 부분 비행 근거를 구별합니다.
- 실제 Boxer 스틱·아밍 스위치·USB 분리/재연결·다른 물리 PC/새 Windows 사용자/다른 GPU는 미검증입니다. Windows 장치 열거는 실물 입력 검증이 아닙니다.
- 한국어/영어는 주요 조종기·첫 비행·AI 화면 우선입니다. 모든 내부 문구·추가 국가 언어 지원 완료가 아닙니다.
- 설치 EXE는 미서명이며 Windows 게시자/SmartScreen 경고가 날 수 있습니다. .NET Framework4.8, Windows10/11x64와 게임용 VC++·DX12 SM6 조건이 필요합니다. VC 설치는 동봉 파일을 사용자가 선택합니다.

- 게임 내 F7 신고창, 탑건 통합·국가/세계 순위·온라인 경기, 추가 언어와 정밀 물리는 후속입니다. 이번 배포의 완료 기능이 아닙니다.
