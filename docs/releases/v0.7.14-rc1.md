# v0.7.14-rc1 · HUD·AI 기록 비교 업데이트

**사전 배포판 — 다운로드 자산은 릴리스 페이지에서 확인한다.** [공개 여부와 다운로드 자산](https://github.com/sun475300-sudo/Drone-Soccer-Simulator/releases/tag/v0.7.14-rc1)을 확인한다. 기존 v0.7.13-rc1과 자산은 보존한다. 실물 장비 등 남은 검증은 아래에 별도로 기록한다.

## 변경

- HUD 측정·그리기에 최소10px 요청 크기를 적용하고 UTF-16 문자 쌍을 보존하는 말줄임과 잘린 상태/장치명 상세를 추가했다. 실제 Windows 장치명은 번역 사전을 거치지 않는다.
- AI 설정/저장 결과에서 읽기 전용 기록 비교 UI를 제공한다. A/B를 직접 선택하고, 기록된 조건·버전·소스 지문·세션·자동 검사/중도 종료를 확인해 비교 가능 여부와 이유를 표시한다.
- F6 시작·중간·종료 쓰기 실패의 안내를 유지하고 명시적 재시도를 검증했다. 가드 파편 슬롯의 불필요한 갱신을 줄였으나 실측 FPS 향상으로 표시하지 않는다.
- 전체 프로그램 ZIP과 설치 EXE를 새 버전 자산으로 준비했다. 설치 폴더를 나눠도 기본 사용자 데이터는 같은 LOCALAPPDATA의 ImperialWingsSimulator/Saved를 공유한다.

## 현재 확인한 근거

새 rc는 clean 4617a4f에서 빌드했다. Editor compile·Shipping compile/cook/stage/archive 종료0, 빌드 전후 입력169개 지문은 bd1e2cf9bf8b4bbe6e731859c31b8febca588d838cc9c8693bb6c23880bcfa8b로 같다. Shipping SHA-256은 50d88da9f997224d967063a984e7d8b374e04cc9be294382a096d8f6f1ef2497이다.

같은 지문으로 비교4조건 각각77개·첫 비행2조건 각각43개·F6 35개·입력29개·물리20/30/60/120/240 고정 간격·GPU720p/960×640 한영 UI 각각55개를 통과했다. 실제240FPS 렌더 성능이나 사람의 비행 능력 측정은 아니다.

133파일 ZIP을 새 한글/공백 경로로 해제하고 CRC·SHA를 확인했다. 포터블13개·설치기CLI65개·공개v0.7.13→새v0.7.14 업데이트CLI50개가 각각 통과했다. 설치·동일버전갱신·실패복구·분리설치·삭제보존·기존ZIP/설치본갱신·실제파일잠금 거부를 QA 전용 경로에서 확인했다. 별도로 새 ZIP의 960×640 실제 창과 업데이트 설치본의 일반 실행기→720p 창에서 한영 비교·안전·F6 저장·정상 종료를 확인했다. 실제 입력은 자동 시험이고 설치기 GUI 전체 검증은 미검증이다.

Boxer 프로필을 QA 경로에 복사한 선택 검사는 실물 장치 부재로 활성화/round-trip 선행조건에 실패했다. 키보드 시작·저장 프로필 발견·종료비활성은 확인했으나 이 실패를 실물 재연결 통과로 세지 않는다.

## 제한과 후속

실물 Boxer 비행·아밍·USB손실/재연결, 다른 물리PC·최초VC환경, 실제 사람 기록 비교·초보자·고DPI 및 이번 rc 전체6단계 연속 비행은 미검증이다. 비교 목록은 파일명순 최대100개이며 AI 결과schema1/2만 지원한다. 통계는 B−A로서 실력 인증·온라인 검증 또는 모든 물리/입력 조건의 일치를 뜻하지 않는다. F6/F5는 비교 입력이 아니다.

설치·제거는 사용자 데이터 보존 정책을 따르며 EXE 하나만 꺼내 실행하지 않는다. 프로그램은 서명되지 않았으므로 Windows/브라우저 경고가 표시될 수 있다.

**main의 게임 코드는 v0.7.4 기반 그대로다.** 새 버전의 개발·빌드는 [v0.7.14-rc1 태그](https://github.com/sun475300-sudo/Drone-Soccer-Simulator/tree/v0.7.14-rc1)를 사용한다. 이번 main 변경은 문서만이다.
