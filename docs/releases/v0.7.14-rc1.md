# v0.7.14-rc1 · HUD·AI 기록 비교 사전 배포 후보

빌드·검증·패키징한 후보의 범위입니다. 공개 여부와 다운로드는 [릴리스 페이지](https://github.com/sun475300-sudo/Drone-Soccer-Simulator/releases/tag/v0.7.14-rc1)에서 확인하세요. 기존 v0.7.13-rc1 자산은 덮어쓰지 않습니다.

## 달라진 점

- HUD 글자 크기·말줄임을 개선하고 Windows가 제공한 장치명을 번역하지 않고 표시합니다.
- AI 설정 또는 저장된 결과에서 기준 A와 비교 B를 선택해 기록을 비교합니다. 저장된 조건·버전·소스 지문이 다르거나 같은 세션, 자동 검사, 중도 종료일 때는 차단 이유를 표시합니다. 비교는 저장된 조건에 대한 기술 통계이며 실력 인증이 아닙니다.
- F6 기록 시작·중간·종료 쓰기 실패 시 실패 안내가 성공 메시지에 덮이지 않도록 개선했습니다.

목록은 파일명 순 최대 100개입니다. AI 결과 schema 1/2를 지원하며 F6 JSONL·F5 CSV는 비교 입력이 아닙니다. 기록되지 않은 배터리·조종 입력 등 모든 훈련 조건의 일치를 보증하지 않습니다. [비교 사용법](../ai-result-comparison.md)을 참고하세요.

## 남은 검증과 설치 시 주의

실물 Boxer 스틱·아밍·USB 손실/재연결, 다른 물리 PC·새 Windows 및 VC 환경, 사람의 AI 기록 비교, 초보자 사용성, Windows 125~200% DPI와 첫 비행 6단계 연속 완주는 미검증입니다. 한국어·영어의 모든 내부 문구나 추가 언어가 완성된 상태는 아닙니다.

설치기에서 별도 폴더 또는 기존 설치 업데이트를 선택합니다. 기존 프로그램 백업은 보존되며, 별도 폴더도 기본 %LOCALAPPDATA%/ImperialWingsSimulator/Saved 설정·기록을 공유합니다. 전원 차단·강제 종료 시 자동 복구는 보장하지 않습니다. 이 실행 파일과 설치기는 서명되지 않아 Windows 또는 브라우저 경고가 표시될 수 있습니다. 필수 VC 구성 요소가 없다면 동봉된 파일의 설치 여부는 사용자가 선택합니다.
