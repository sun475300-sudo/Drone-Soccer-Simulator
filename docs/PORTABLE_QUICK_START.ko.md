# Imperial Wings 다른 PC에서 시작하기

**v0.7.14-rc1 — HUD·AI 기록 비교·저장 실패 안내 개선 사전 배포.** 처음 조종기 화면은 한국어로 열립니다. 패널의 언어 버튼으로 English/한국어를 바꾸며 이 선택은 Windows 사용자별 `Config/Language.txt`에 보정과 따로 저장됩니다. 한국어 지원은 조종기·첫 비행·AI 설정과 결과 안내를 우선 적용했습니다. 일부 경기·내부 상태 메시지에는 영어가 남을 수 있습니다.

기존 Mode1/2 단계형 보정·레이트/Expo·아밍키와 최신 AI 연습/3분 대전까지 포함합니다. AI PRACTICE → DUEL / 3 MINUTES는 한 명이 파란 공격수를 직접 조종하는 로컬 훈련 변형이며 정식 5대5 멀티플레이가 아닙니다. 진행 중인 Topgun 코스는 포함하지 않았습니다. 실제 Boxer 연속 비행·케이블 손실 복구·다른 PC 확인은 미검증입니다.


## 키보드 첫 비행

처음에는 **키보드 사용 → 닫기**, 수동 연습에서 **F1**을 누릅니다. 안내 시작은 모터를 켜지 않습니다. **이륙 → 제자리 비행 → 이동 → 착륙 → 첫 골 → 마지막 착륙**의 조건을 충족하면 직접 다음을 누릅니다.

Space로 ARM/DISARM, ↑/↓로 스로틀, W/S·A/D로 기울기, Q/E로 회전합니다. 키를 놓아도 스로틀은 유지되며 ANGLE은 고도 유지가 아닙니다. 착륙 후 다음 단계에서는 최저 스로틀·키 중립을 확인하고 직접 Space로 ARM하여 다시 이륙합니다. 첫 골 성공과 마지막 착륙·모터 정지는 별도 조건입니다. F1로 안내를 닫아도 비행은 계속됩니다.

기본 조종 설정은 부드러운 응답을 미리 보고 취소하거나 저장할 수 있습니다. 세부 레이트·Expo·아밍키는 고급 설정을 사용합니다. AI 연습 진행 중 대수·난이도·배치는 잠기며 AI 종료는 상대 기체만 착륙시킵니다.

별도 폴더에 설치해도 기본 사용자 설정·보정·기록은 `%LOCALAPPDATA%/ImperialWingsSimulator/Saved`를 공유합니다. 새 버전 설치는 개인 데이터를 삭제하지 않습니다. 실물 조종기와 다른 PC, 첫 비행 6단계 전체 실제 비행은 별도 검증 대기입니다.

## 실행과 USB 조종기

1. Windows 배포 ZIP **전체를 압축 해제**합니다. EXE만 따로 복사하지 않습니다.
2. `ImperialWingsLauncher.exe`를 실행합니다. Unreal Engine·Python·Git 설치는 필요 없습니다.
3. 필수 Visual C++ 구성요소 설치 창이 나오면 설치를 마친 뒤 다시 실행합니다. 설치 파일은 `Prerequisites`에 포함돼 있습니다.
4. **조종기 설정:** 사용하는 조종기의 데이터 전송용 USB 포트에 데이터 케이블을 연결합니다. 기종에 따라 전원을 켜고 **USB Joystick / 게임 컨트롤러 모드**를 선택합니다. 충전 전용 케이블·포트로는 입력을 읽을 수 없습니다.
5. 처음 열린 간소 설정 화면에서 **장치 카드**로 조종기를 직접 선택합니다. **REFRESH / NEXT DEVICE**(새로 검색 / 다음 장치)도 사용할 수 있습니다. 상단 STEP 안내를 따르고 X/Y/Z/R/U/V 막대가 실제 스틱 움직임에 따라 변하는지 확인합니다.
6. 실제 스틱 배치에 따라 **MODE 1**(오른쪽 세로 스로틀) 또는 **MODE 2**(왼쪽 세로 스로틀)를 선택하고 **STICK SETUP**을 누릅니다. Roll → Pitch → Yaw → Throttle 순서로 화면이 지정한 스틱만 양 끝에서 1초씩 유지합니다. Mode 1의 Pitch는 왼쪽, Throttle은 오른쪽입니다. Mode 2의 Pitch는 오른쪽, Throttle은 왼쪽입니다. 마지막 유지 위치와 중립 수집 안내를 따릅니다.
7. **CONFIRM & SAVE**(검토 후 저장) 후, 스로틀을 맨 아래로 두고 **ENABLE RADIO**를 누릅니다. 패널을 닫은 뒤 **Space**로 ARM합니다. 다른 스틱은 중앙에서 시작합니다.

각 PC의 실제 축 순서와 방향을 보정합니다. 개발 PC의 개인 조종기 보정값은 배포본에 들어 있지 않습니다. Mode 1·Mode 2 모두 단계별 보정을 지원합니다. 모드를 변경하면 USB가 해제되며 새 보정을 저장한 뒤 활성화해야 합니다. 수동 설정이 필요하면 **ADVANCED OPTIONS**의 AXIS/NORMAL·INVERTED 버튼과 범위 보정으로 실제 축을 수동 설정합니다. **SIMPLE VIEW**로 기본 화면에 돌아옵니다. 기본 입력 API는 Windows WinMM 조이스틱입니다. 모든 HID·XInput 장치가 호환된다고 보장하지 않으며, 네 개의 서로 다른 아날로그 축이 필요합니다.

모든 기체는 ANGLE이며, 스틱을 놓으면 수평을 복원합니다. 고도는 스로틀로 조절합니다. 기본 시점은 경기장 밖 조종자 위치의 LOS입니다. USB 활성화와 ARM은 매번 별도이며 저장된 보정값으로 자동 이륙하지 않습니다.

다음 실행에는 C로 설정을 열어 **CONNECT SAVED RADIO**를 누르거나, 최저 스로틀에서 **F8**로 일치하는 저장 프로필을 연결합니다. 장치 슬롯·펌웨어·모델 출력 설정이 바뀌면 다시 선택·보정해야 할 수 있습니다. 게임 포커스나 USB 연결이 끊기면 수동 USB 기체가 DISARM되며, 다시 연결해도 자동 재개하지 않습니다.

v0.7.1에서는 키보드 수동 기체도 창 포커스 상실 시 DISARM하고 누적 스로틀·축 입력을 지웁니다. 키를 놓고 새로 눌러 조종하며 ARM은 별도로 수행합니다. 메뉴·장비 보기·기체 전환·초기화에서 이어진 자동 반복 입력도 차단합니다. 연습 AUTO는 계속되며, 메뉴에서 명시적으로 켠 USB 연결은 메뉴를 닫을 때 보존합니다. 실제 USB 원시 값과 저장 보정값을 임의로 중립으로 바꾸지 않습니다.

설정과 진단은 `%LOCALAPPDATA%\ImperialWingsSimulator\Saved`에 저장됩니다. `Config\RadioProfile.json`은 해당 Windows 사용자의 보정값, `Config\VisualQuality.txt`는 화질, `Config\Language.txt`는 표시 언어입니다. 버전 업데이트는 새 폴더에 압축 해제해도 설정을 유지합니다. 다른 사람에게 이 사용자 데이터 폴더를 복사하지 않습니다.

연결 문제는 설정 화면의 **EXPORT DEVICE REPORT**를 눌러 `Diagnostics`의 JSON을 확인합니다. 장치가 없으면 Windows의 `joy.cpl`에서도 움직이는지 먼저 확인합니다. 진단 파일에는 사용자 저장 경로와 장치 이름이 들어 있으므로 공개 저장소에는 올리지 않습니다.

**비행 데이터 수집:** F6로 연속 기록을 시작하고 다시 눌러 종료합니다. 결과는 사용자 데이터의 `FlightLogs/*.jsonl`입니다. F5는 그 순간의10대 상태를 `Reports/*-fleet.csv`로 저장합니다. 착륙·DISARM·F6 종료 후 폴더를 확인합니다. [릴리스 사용·검증 안내](https://github.com/sun475300-sudo/Drone-Soccer-Simulator/releases/tag/v0.7.14-rc1)를 참고하세요.

**테스트 피드백 작성:** ZIP 전체를 압축 해제한 폴더에서 `feedback-form.html`을 Edge 또는 Chrome으로 직접 엽니다. 실제 실행한 버전·ZIP 이름과 직접 확인한 결과를 적고 **보고서 미리보기 → 내용 확인란 → TXT 보고서 저장 / JSON 보고서 저장** 순서로 저장합니다. 브라우저 다운로드 목록에서 저장된 파일을 확인합니다. 내용을 고치면 미리보기를 다시 확인하고, 창을 닫거나 새로고침하기 전에 저장하세요. HTML은 인터넷·로그인 없이 사용하는 별도 양식이며 게임이나 조종기 설정을 변경하지 않습니다.

저장한 TXT 또는 JSON과 필요한 화면·비행 기록만 배포자에게 직접 전달합니다. 양식의 첨부란은 파일 이름·설명 메모이며 파일을 읽거나 포함하지 않고 자동 전송하지 않습니다. `Config/RadioProfile.json`이나 사용자 `Saved` 전체를 보내지 않습니다. HTML을 열거나 저장할 수 없으면 실제 버전·입력 방식·재현 순서·기대/실제 동작을 텍스트로 적어 전달하세요.

자율 훈련용 실제 SDACS APF·Python·NumPy는 배포 폴더에 포함됩니다. 실행기는 로컬 전용 연결을 빈 포트에 만들고 게임 종료 시 함께 종료합니다. 자율 연결이 실패해도 수동 조종은 가능합니다. 공식 경기 조종은 사람이 수행하며 AUTO/HOLD/RETURN은 연습 보조입니다.

v0.7의 보기: **1 파일럿 LOS / 2 추적 관찰자 / 3 경기장 전체 / 4 관객석 / 5 심판 측면**입니다. 관객·심판 보기는 비행 조작을 제한합니다. 수동 기체를 먼저 DISARM하고 전환하세요. **F9 EQUIPMENT**는 DISARM한 기체의 내부 장비를 보여 주며, 다시 F9로 LOS에 돌아옵니다. 장비 보기에서는 ARM하지 않습니다.

선택 기체의 **GUARD %**는 충격량에 따른 실험적 내구도 지표입니다. 충돌에서 마모 흔적·파편 효과와 이벤트가 발생하며 Backspace/RESET으로 복원합니다. 실제 부품 파단·모터 고장 모델이나 실물 수명 예측은 아닙니다. 연습 골대에는 작은 앞뒤 반응을, 정규 경기에는 고정 지지를 적용합니다.

지원 대상은 Windows 10/11 x64, DirectX 12·Shader Model 6을 지원하는 GPU와 최신 드라이버입니다. 기본 화질은 Balanced이며 게임의 GRAPHICS에서 조절합니다. 모든 GPU·조종기·Windows 조합이나 실제 다른 PC의 USB 비행을 인증한 버전은 아닙니다. 개발 PC의 분리된 새 사용자 데이터·한글/공백 경로·설치 Python/Git 경로를 뺀 실행 검사는 공개 검증 기록에 따로 남깁니다.

종료는 게임 상단 **EXIT** 또는 창 닫기를 사용합니다. 배포본의 `SHA256SUMS.txt`와 `release-manifest.json`은 파일 손상·버전 확인용이며 코드 서명을 대체하지 않습니다.

## AI 저장 기록 비교

AI 설정 또는 저장된 최근 결과의 **저장 기록 비교**에서 기준 A와 비교 B를 직접 선택합니다. 다른 조건·버전·소스, 자동 검사, 중도 종료, 같은 세션은 비교가 차단됩니다. 허용된 통계는 B−A이며 실력 인증이 아닙니다. 목록은 파일명 순 최대100개이고 명시적으로 새로고침할 때 읽습니다. 원본 파일은 유지하며 F6 JSONL과 F5 CSV는 비교 입력이 아닙니다. 사람 기록 비교·초보자 사용성·Windows125~200%DPI는 미검증입니다.
